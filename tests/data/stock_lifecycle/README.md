# Synthetic lifecycle exporter fixture

Generated by `dev/stock_vintage/generate_lifecycle_fixture.py` on the premise
`feat/stock-vintage-pilots` branch. The source inventories and lifetime are
invented for testing; this contains no licensed ecoinvent inventory. The
biosphere index is the public flow dictionary shipped with premise. Recreate
the ZIP and `expectations.json` together with that script, then run
`dev/stock_vintage/check_lifecycle_roundtrip.py` in the TRAILS environment.

The actual premise matrix writer and package builder export 2020/2022 anchors.
An initial stock of three 2005 assets and one 2015 asset grows by one new asset
in 2021 and 2022. A fixed 20-year life gives retirement in 2025/2035/2041/2042.
The scoped service supplies 0.3 kg CO2, manufacture 0.2 kg and the signed
recycling credit -0.05 kg per unit service. Corrected production and disposal
must retain these dates, including when background matrices end at 2023.

Tests independently compute annual biosphere amounts from these known values,
in addition to checking the generated cohort records. Both signed functional
units, repeated/reversed service years, root attribution, annual interpolation
and direct/Brightway solvers are covered.
